# HGPS computational model outputs — private staging

These 9 CSV files are existing computational/model-derived outputs selected from the HGPS V5 private archive. Original bytes and numerical values have not been changed. See `MODEL_DATA_SHA256_MANIFEST.csv` for provenance hashes and row counts.

**Interpretation:** These files are exploratory hypothetical model outputs. They are **not independent patients, empirical pharmacodynamic validation, actual 3D treatment-CFD results, observed toxicity, clinical superiority, or validated dosing guidance.** Their original analysis methods, input provenance, and licensing require separate review before publication.

**Access:** Intended only for the existing GitHub **PRIVATE** repository. Do not make the repository public or transfer this staging package to a public Zenodo deposit without institutional, IP, data protection, and scientific review.

**Excluded:** All patient-derived coordinates/meshes/DICOM, original-source inventories with absolute paths, third-party published aggregates, other unreviewed data, and all research code (uploaded separately).
